# 3단계: 탐색적 데이터 분석 (EDA)

> Branch: `feature/03-eda`

---

## 목표

수집된 데이터를 기반으로 배달의 민족 도메인의 주요 패턴과 인사이트를 탐색합니다.

---

## 작업 항목

- [ ] 기초 통계 분석
  - 주문량 분포 (시간대별, 지역별, 요일별)
  - 평균 배달 시간 분포
  - 가맹점별 주문 현황
- [ ] 주요 KPI 탐색
  - 고객 주문 빈도 (재주문율)
  - 라이더 배달 완료율
  - 쿠폰 사용 패턴
- [ ] 데이터 품질 이슈 탐지
  - 결측값 / 이상값 탐지
  - 거래 취소 패턴 분석
- [ ] 상관관계 분석
  - 날씨 / 시간대 vs 주문량
  - 리뷰 점수 vs 재주문율
