# 5단계: 결과 시각화 및 리포트 작성

> Branch: `feature/05-reporting`

---

## 목표

전체 분석 결과를 시각화하고 비즈니스 인사이트를 담은 최종 리포트를 작성합니다.

---

## 작업 항목

- [ ] 대시보드 설계
  - 실시간 주문 현황 대시보드
  - 가맹점별 성과 리포트
  - 라이더 효율 분석 차트
- [ ] 분석 결과 시각화
  - 주문 예측 모델 결과 시각화
  - 고객 이탈 위험 세그먼트 차트
  - 지역별 수요 히트맵
- [ ] 최종 리포트 작성
  - 프로젝트 요약 및 비즈니스 임팩트
  - 주요 발견사항 (Key Findings)
  - 개선 제안 (Recommendations)
- [ ] 발표 자료 준비
